# Vijesh M - Personal Portfolio Website

A modern, interactive personal portfolio website for Vijesh M built with HTML, CSS, JavaScript, and Three.js for 3D effects.

## Features

- Interactive 3D particle background created with Three.js
- Smooth animations and transitions using GSAP
- Responsive design for all device sizes
- Modern UI with parallax effects
- Interactive project cards with 3D tilt effect
- Animated skill bars and timeline
- Contact form with animations
- Typewriter effect for hero text

## Technologies Used

- HTML5 & CSS3
- JavaScript (ES6+)
- Three.js for 3D graphics
- GSAP (GreenSock Animation Platform) for animations
- FontAwesome for icons
- Google Fonts

## Setup Instructions

1. Clone the repository or download the files
2. Open the index.html file in a web browser
3. No build tools or installations required - it's a static website

## Features in Detail

### Three.js Background
- Interactive 3D particle system that responds to mouse movement
- Custom color theme matching the portfolio's design
- Optimized for performance across devices

### Animation System
- Page load animations
- Scroll-triggered animations using GSAP ScrollTrigger
- Interactive elements with hover effects
- Smooth scrolling navigation

### Responsive Design
- Mobile-first approach
- Hamburger menu for smaller screens
- Flexible grid layouts
- Optimized for all device sizes and orientations
